Etiquetas Semanticas

Las etiquetas semanticas son aquellas que nos permiten dar un significado a nuestro contenido, es decir, nos permiten indicar que tipo de contenido estamos mostrando en nuestro documento HTML5.

Etiquetas semanticas

  • <header>: Esta etiqueta nos permite definir el encabezado de nuestro documento HTML5.
  • <nav>: Esta etiqueta nos permite definir la barra de navegacion de nuestro documento HTML5.
  • <main>: Esta etiqueta nos permite definir el contenido principal de nuestro documento HTML5.
  • <article>: Esta etiqueta nos permite definir un articulo dentro de nuestro documento HTML5.
  • <section>: Esta etiqueta nos permite definir una seccion dentro de nuestro documento HTML5.
  • <aside>: Esta etiqueta nos permite definir un contenido adicional dentro de nuestro documento HTML5.
  • <footer>: Esta etiqueta nos permite definir el pie de pagina de nuestro documento HTML5.

Procedimiento para crear un documento HTML5

  1. Crear un archivo con extension .html
  2. Escribir la estructura basica de un documento HTML5
  3. Agregar las etiquetas semanticas que nos ofrece HTML5
  4. Agregar contenido a nuestro documento HTML5
  5. Guardar nuestro documento HTML5
  6. Abrir nuestro documento HTML5 en un navegador web
